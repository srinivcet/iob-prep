📱 PWA Setup Guide — IOB Prep

PWA (Progressive Web App) lets you install IOB Prep like a native app on your phone — home-screen icon, full-screen mode, works 100% offline after first install.

⚠️ Important: PWAs need to be served over HTTPS. Opening files directly (file://) won't register the service worker. Use one of the 3 options below.

🎯 Option 1: GitHub Pages (Recommended, FREE)

Best for sharing + installing on phone. Takes 5 minutes.

Step 1: Create a GitHub account (if you don't have one) → github.com/signup
Step 2: Create new repo named iob-prep → make it public.
Step 3: Upload ALL files from this folder (all .html + .png + .json + .js) to the repo root.
Step 4: Go to Settings → Pages → Source: "Deploy from branch" → Branch: main → Save.
Step 5: Wait 1-2 min. GitHub gives you a URL like https://<username>.github.io/iob-prep/IOB_Study_Hub.html
Step 6: Open that URL on your phone (Chrome). Click the install banner, OR Chrome menu → "Install app" / "Add to Home Screen".
✅ Installed. Now works offline forever. Access via home-screen icon.

📦 Option 2: Wrap as APK via PWABuilder

Install directly as Android app (like Play Store app but sideloaded).

Prerequisite: Complete Option 1 first (get a public HTTPS URL).
Step 1: Go to pwabuilder.com
Step 2: Enter your GitHub Pages URL → click "Start".
Step 3: Review the PWA checks → click "Package For Stores".
Step 4: Choose "Android" → download signed APK.
Step 5: Transfer APK to phone → enable "Install from unknown sources" → install.
✅ Installed as native Android app with icon, splash screen, etc.
📝 This is exactly how you built your other PWAs (Scroll Limit, Gut Reboot Tracker) — same process.

💻 Option 3: Local Webserver (Quick test)

Test PWA on your phone without uploading anywhere.

Step 1: Install an app like "PWA Server" or "Simple HTTP Server" from Play Store.
Step 2: Point it to this folder on your phone.
Step 3: App gives local URL like http://localhost:8080.
Step 4: Open in Chrome → install.
⚠️ Only works while the server app is running. GitHub Pages is better for permanent install.

🔍 How to verify PWA is working

  • Open the Hub URL in Chrome.
  • Chrome menu → "Install app" option should appear.
  • Or install banner appears at bottom of Hub automatically.
  • After install → app icon on home screen.
  • Open app → should launch in full-screen (no browser bar).
  • Turn off WiFi + data → open app → everything still works.

📂 Files in your PWA

All 16 files are needed for the PWA to work offline:

  • 13 HTML files — Study Hub + 11 Modules + Tracker + Crash Notes
  • manifest.json — PWA metadata (name, icons, start URL)
  • sw.js — Service Worker (caches everything for offline)
  • icon-192.png, icon-512.png, icon-maskable-512.png — App icons

🔄 Updating the PWA

If I send you updated files later (e.g., new animations, more MCQs):

  1. Replace the files in your GitHub repo.
  2. Update CACHE_NAME in sw.js (e.g., 'iob-prep-v1.0.1').
  3. Within hours, PWA auto-updates on next launch.
